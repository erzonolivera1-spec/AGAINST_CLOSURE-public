# Against Closure

Neil Erzon Olivera

Edition One

Some decisions can be reversed. Others cannot.

The ones that cannot be undone are the ones a person, an institution, or a
civilization needs to get right before making them, because there is no
correcting them afterward.

*Against Closure* is about the moment before that kind of decision gets
made: what a mind mistakes for certainty, what an institution mistakes for
settled, and why claiming to know enough to close a question permanently
is a claim almost no one is ever entitled to make.

Its argument is that truth, for a person or an institution, is not a
state you reach and then hold. It is a process that has to stay open to
being wrong, for as long as being wrong is still possible.

## What's inside

35 chapters, built around 22 core distinctions and illustrated across
20 diagrams, with a glossary for readers coming to the argument fresh.
